### Segurança

- **Bug crítico corrigido**: `onAuthStateChanged` usava `localStorage.getItem("mutantes_docid")` para decidir qual perfil carregar. Se o localStorage estivesse errado ou vazio, caía no fallback `{isAdmin:true}` — concedendo acesso de admin para qualquer usuário autenticado sem perfil encontrado.
- **Correção**: `onAuthStateChanged` agora consulta Firestore com `where("uid","==",user.uid)`. Fallback para admin verifica o doc `usuarios/admin` pelo email e persiste o `uid` para buscas futuras. Se nenhum perfil válido for encontrado, faz `signOut()` e retorna à tela de login.
- `cadastrarEmLote` também corrigido: não lê mais `localStorage` para restaurar `MY_DOC_ID` após cadastro de membro.

## Pendências / bugs conhecidos

- **Presença retroativa — sem recarregar lista**: após confirmar presença retroativa, o contador de presenças na sede é incrementado em memória (`SEDE_COUNTS`), mas o histórico visual na tela (card "Histórico") não recarrega automaticamente — o usuário precisa navegar para outra tela e voltar.

- **PDF — foto do membro**: a foto de perfil no PDF usa a URL do Cloudinary diretamente. Dependendo do CORS da conta Cloudinary, pode falhar silenciosamente e não exibir a foto (jsPDF usa `canvas` para embutir imagens).

- **Admin sem campo `uid` no Firestore**: o doc `usuarios/admin` provavelmente não tem o campo `uid` preenchido. O fallback por email funciona no primeiro login e persiste o campo — mas se o Firestore estiver offline nesse momento, o `setDoc` de persistência pode falhar silenciosamente (`.catch(()=>{})`).

- **`cadastrarEmLote` — race condition suave**: após criar novo membro e reconectar como admin, `MY_DOC_ID` é setado como `"admin"` manualmente antes de `onAuthStateChanged` terminar. O `render()` chamado logo em seguida usa `UP` possivelmente desatualizado; `onAuthStateChanged` faz um segundo `render()` correto na sequência.

- **Histórico de graduações — sem validação de ordem**: é possível adicionar uma graduação com data anterior à mais recente sem aviso. Não afeta funcionamento, mas pode gerar timeline fora de ordem cronológica.
